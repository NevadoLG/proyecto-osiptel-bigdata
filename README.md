# Proyecto Big Data - OSIPTEL

Big data y analitica para el Monitoreo de la Brecha Digital y Despliegue de Infraestructura de Telecomunicaciones Fijas


## Arquitectura
La solución utiliza una arquitectura on-premise basada en Hadoop HDFS, YARN, Apache Spark, PySpark y JupyterLab.

## Fuente de datos
Datos abiertos de PUNKU - OSIPTEL.
